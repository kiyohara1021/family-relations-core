## [0.1.0] - 2026-08-14

### Added

- English and Japanese kinship descriptions based on closest shared ancestors.
- Japanese and English sibling birth-order labels.
- Structured family graph validation, including iterative cycle detection.
- Deterministic household-aware layout coordinates.
- Anonymous fixture and local-only browser playground.
- Node.js 24 and 26 CI, GitHub Pages workflow, and public project documentation.
